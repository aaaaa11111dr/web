🚀 如何部署

要完整运行此系统，请按照以下步骤：

  1. 在云服务器上安装 Docker 和 Docker Compose
  2. 上传项目文件到服务器
  3. 运行 docker-compose up -d
  4. 访问 http://your-server-ip:8000
  5. 默认管理账号：admin / Admin1234
